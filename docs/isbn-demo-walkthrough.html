Step 1 — Update the book model

src/models/Book.js (constructor, validation, serialization)

  • Add isbn = null to the constructor signature.
  • Set this.isbn = isbn.
  • In validate(), allow ISBN to be optional, but if present it must be a non-empty string.
  • In toJSON(), include isbn in the returned object.
// add isbn to constructor
constructor(id, title, author, year = null, isbn = null) { ... }

// validate optional isbn
if (data.isbn != null && (typeof data.isbn !== 'string' || !data.isbn.trim())) {
  return { isValid: false, error: 'ISBN must be a non-empty string' };
}

// include in response shape
isbn: this.isbn

src/database/db.js (seed data, createBook, updateBook)

  • Add ISBN values to the seeded books so GET responses visibly include the new field.
  • In createBook(), persist trimmed ISBN when provided; otherwise store null.

Step 3 — Keep PUT validation consistent

src/routes/books.js (update route merge object)

  • Extend the merged object used for validation during PUT.
  • This ensures partial updates validate against the final state, including ISBN.
const merged = {
  title: updates.title ?? book.title,
  author: updates.author ?? book.author,
  year: updates.year !== undefined ? updates.year : book.year,
  isbn: updates.isbn !== undefined ? updates.isbn : book.isbn
};

Pause and ask: “Do you understand why the route merge needs ISBN too, even though this demo is focused on POST?”
